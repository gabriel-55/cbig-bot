## コマンド一覧と使い方

### ベスト枠画像の生成
*   **`c!gen [ユーザー名]`**
    指定したchunirecのユーザー名でベスト枠画像を生成し、Discord上に画像を出力します。`.scoresup` ファイルが指定されていれば、そのファイルのデータを使用して生成します。
    （例: `c!gen chunithm_player`）

### データ編集・管理コマンド
`.scoresup` ファイル内のスコアを閲覧・編集するためのコマンドです。処理が完了すると、Botが更新済みの新しい `.scoresup` ファイルを返信します。

*   **`c!view`**
    ファイルに収録されている楽曲を番号付きのリストで一覧表示します。スコア編集などで使う「曲の番号」はここで確認できます。
*   **`c!score [番号] [スコア] ...`**
    指定した番号の楽曲のスコアを更新します。
    （例: `c!score 1 1010000 3 998000` ＝ 1番の曲を1010000点に、3番の曲を998000点に更新）
*   **`c!fc [番号] ...` / `c!aj [番号] ...`**
    指定した番号の楽曲に フルコンボ（FC） または オールジャスティス（AJ） の状態を切り替えます。
    （例: `c!fc 1 3 5` ＝ 1, 3, 5番の曲のFC状態をON/OFF）
*   **`c!update`**
    Botから最新の楽曲リストを取得し、今まで登録したスコアデータを引き継いだ新しい `.scoresup` ファイルを作成します。新曲が追加された際などに使用します。
*   **`c!clean (番号 ...)`**
    スコアが「0」の未プレイ楽曲を一括で削除し、データを整理します。番号を指定した場合は、その番号の曲だけをピンポイントで削除します。
    （例: `c!clean 1 3 5` ＝ 1, 3, 5番の曲を削除）
*   **`c!detail [番号]`**
    指定した番号の楽曲の、より詳細なデータを確認します。
*   **`c!help`**
    ヘルプを確認できます。

### .scoresup ファイルについて
データ編集コマンドを使用する際は、スコアデータである `.scoresup` ファイルをメッセージに添付するか、ファイルがある過去のメッセージに返信する形でコマンドを実行してください。

## インストール・セットアップ方法

### 1. 事前準備
- **Node.js** がインストールされている必要があります。
- **Discord Developer Portal** にてBotアプリケーションを作成し、「Bot Token」を取得しておいてください。

### 2. パッケージのインストール
Botのソースコードがあるディレクトリに移動し、以下のコマンドを実行してください。

```bash
npm install
```

### 3. 設定ファイル（config.json）の作成
Botのディレクトリ内に `config.json` という名前のファイルを作成し、以下の形式で取得したTokenを記述して保存してください。

```json
{
  "token": "ここに取得したDiscord_Bot_Tokenを貼り付けてください"
}
```

### 4. Botの起動
以下のコマンドを実行してBotを起動してください。

```bash
node index.js
```

Discord上でBotがオンラインになれば成功です。
